# AUTO Battle feedback template

Thank you for testing. Please include the following when reporting a problem:

1. Mod version and whether AUTO was bright (ON) or dim (OFF).
2. A full in-game screenshot at the moment of the issue.
3. `BepInEx\\LogOutput.log` after closing the game normally. Include
   `BepInEx\\ErrorLog.log` too, if it exists.
4. Short reproduction steps: room type, active hero effects, available action
   tiles, what AUTO did, and what you expected.
5. For the v0.6.30 trap-horizon test: the next room's trap, the hero's
   remaining health/morale, and whether the forecast matched the actual trap.

Never send saves or the original game files unless explicitly requested.
