# Как сообщать о багах

На этапе тестирования пишите мне в Steam-чат — не создавайте GitHub Issue.

После воспроизведения ошибки:

1. Сделайте **полный** скриншот окна игры. На нём должна быть видна AUTO-иконка
   в правом верхнем углу и экран, на котором мод остановился или выбрал неверно.
2. Закройте игру обычным способом, чтобы журнал был полностью записан.
3. Прикрепите `BepInEx\LogOutput.log`. Если есть `BepInEx\ErrorLog.log`,
   приложите и его.
4. Напишите: что происходило, где (ход монстра / заклинание хозяина / бедствие
   / переход между боями), была ли AUTO-иконка яркой, и что должно было
   случиться.

Шаблон сообщения:

```text
Версия мода: v0.6.27
Что произошло:
Ожидалось:
Фаза: атака монстра / заклинание хозяина / бедствие / переход / кнопка AUTO
AUTO: ON (яркая) / OFF (тусклая) / не знаю
Шаги для повторения:
1.
2.
3.
Приложено: скриншот + LogOutput.log (+ ErrorLog.log, если есть)
```

Не нужно присылать сохранения или всю папку игры, если я отдельно не попрошу.
